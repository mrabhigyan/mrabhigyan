### 👋 About me

- I build things with LLMs and multi-agent systems, mostly to see what happens when AI agents have to figure things out on their own.
- 🔭 Latest project: **[Alien First Contact](https://github.com/mrabhigyan/alien-first-contact)**, two AI agents that invent their own language.
- 🌱 Currently learning **LangGraph** and **Langfuse**.
- 💼 Open to AI / ML roles.

### 🔭 Featured project

<a href="https://github.com/mrabhigyan/alien-first-contact"><img src="https://raw.githubusercontent.com/mrabhigyan/alien-first-contact/main/results/dashboard.png" width="100%" alt="Alien First Contact dashboard"/></a>

**[Alien First Contact](https://github.com/mrabhigyan/alien-first-contact)**: two LLM agents with no shared language invent one from scratch, grammar included. They describe objects they have never seen, and two separately grown dialects still understand each other. Compared against neural networks trained from zero: about 20 games versus 15,000.
